��� COMO COMEÇAR:

  1. Instalar dependências:
     npm install

  2. Configurar .env.local:
     DB_HOST=localhost
     DB_PORT=3306
     DB_USER=root
     DB_PASSWORD=sua_senha
     DB_NAME=cemoque

  3. Criar banco de dados:
     npm run db:create
     npm run db:migrate

  4. Rodar projeto:
     npm run dev

  5. Abrir no navegador:
     http://localhost:5173
