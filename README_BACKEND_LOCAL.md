## 🎯 Arquitetura

```
React (Frontend)
    ↓ HTTP/REST
Express.js (Backend) ← NOVO
    ↓ SQL
SQLite (Banco Local) ← NOVO
    ↓
Seus dados no controle!
```

**Benefícios:**
- ✅ Funciona offline
- ✅ Sincroniza quando volta online
- ✅ Backup fácil (arquivo .db)
- ✅ Sem custos de cloud

---

## ⚡ Comece em 3 Passos

```bash
# 1. Instalar
npm install

# 2. Criar banco
npm run db:migrate

# 3. Rodar
npm run dev
```

**Abre:**
- Frontend: http://localhost:5173
- Backend: http://localhost:5000
